# Gym Ecommerce

## Descripcion

Es un e-commerce de venta de articulos de gimnasio y suplementacion deportiva. El sistema permite a los usuarios registrarse, iniciar sesion, explorar un catalogo de productos filtrable por categoria, genero y grupo de edad, gestionar un carrito de compras y finalizar pedidos con direccion de envio y metodo de pago
